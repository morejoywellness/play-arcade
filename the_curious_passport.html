About the cultural clues & accuracy

This game contains 80 destinations and 320 cultural clue drafts. They are based on real practices, foods, games and places, but the full set has not yet been independently source-verified. Many customs are regional or shared across borders. This is a playable editorial preview, not a fully fact-checked reference. Please verify each entry against reliable local or primary sources before publishing it as educational material.

Progress is stored only in this browser when local storage is available. The game uses no external data service.
